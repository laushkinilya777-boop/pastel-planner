# Дополнения: «Сделать до», Привычки, Бюджет, Идеи, меню

Дата: 24.11.2026 · Статус: утверждено хозяйкой в переписке («начинай»)

## Зачем
Хозяйке нужно больше, чем задачи: срок «до скольки», трекер привычек, бюджет с копилками и месячным планом, место для идей коротких видео. Картинки — в конец меню.

## Решения хозяйки
- У задачи есть срок «Сделать до» (время), видно в списке.
- Бюджет: категории «откуда» и «куда» пишет сама. Каждый месяц — свой красивый план; с новым месяцем план обновляется, накопления (копилки) остаются. «Как популярно, удобно, современно».
- Привычки (как Habitify/Streaks) и Идеи (доска как в Notion) — по моему предложению, одобрено.
- Меню: Сегодня · Неделя · Месяц · Привычки · Бюджет · Идеи · Картинки (картинки последние).

## Мои решения (можно поправить)
- **Сделать до:** поле `due_time`; напоминание остаётся относительно времени начала, а если времени начала нет — относительно срока. В строке задачи метка «до 18:00», просроченная сегодня — красноватая.
- **Привычки:** название, цвет (5 пастельных), дни недели (все или выбранные). Отметка — одна запись в `habit_logs` на день. Серия 🔥 = подряд выполненные «плановые» дни до сегодня (сегодня не ломает серию, пока не закончился). Месячная тепловая карта. Блок «Привычки дня» на странице «Сегодня».
- **Бюджет:** записи трёх видов: доход (откуда), расход (куда), в копилку / из копилки. Копилки с целью и «жидкой» капсулой, баланс = сумма вложений − снятий, не зависит от месяца. План месяца: строки «категория — сумма» (расходы и «отложить»); при первом открытии месяца без плана сайт копирует категории и суммы прошлого месяца (стабильные id, чтобы два устройства не задвоили). Сводка: пришло / потрачено / отложено / осталось, кольцо «потрачено из плана», категории с полосками план/факт. Валюта ₽. Подсказки названий из прошлых записей.
- **Идеи:** название, крючок, сценарий/заметки, ссылка, площадка (Reels/TikTok/обе), теги, статус (Идея → Сценарий → Снимаю → Опубликовано), дата публикации. На телефоне — вкладки статусов, на компьютере — колонки. Дата публикации показывается на странице этого дня.
- **Меню:** на компьютере все 7 пунктов; на телефоне 5: Сегодня · Неделя · Месяц · Привычки · Ещё (Бюджет, Идеи, Картинки).
- Всё новое хранится в Supabase с RLS «только владелец», офлайн-кэш как у задач. Один SQL-файл `supabase/setup-extras.sql` для ручного запуска.
